## 一、轻子谱"脱水版"公式：无解

文档公式：`m_ln = m_e·(n + ln(m_ln/M_Pl))`（m_e=0.511 MeV，M_Pl=1.221×10²² MeV）

| n | 文档声称 | 独立验算 |
|---|---|---|
| 0（电子） | "退化为 m_e=m_e" | `0.511·ln(0.511/1.221e22) = −25.9 MeV ≠ 0.511` ❌ |
| 1（μ） | "解得 105.7，误差 0" | 方程化为 `x − 0.511·ln x = −25.4`；但 `x − 0.511·ln x ≥ 0.855`（最小值在 x=0.511）→ **无解** ❌ |
| 2（τ） | "1777 vs 1776.86，0.008%" | 同上，`x − 0.511·ln x = −24.4` → **无解** ❌ |

**结论**：公式没有正解，连 n=0 都不成立。"零偏差拟合"是编造的数字。

## 二、希格斯质量：κ 是明写的拟合 + 数字差 21 个数量级

- 同文档 κ 从"初始值 0.12"到"提升至 0.8"——拟合被写进流程，却宣称"无需额外拟合"。
- 文档路径：`0.8·(4π)³/(0.1·0.034·(1/137))·(9.7/2.1)²·9.35×10¹⁵ ≈ 7112`
- 独立验算：(4π)³ = 1984；分母 0.1×0.034×(1/137) = 2.48×10⁻⁵；1984/2.48e-5 = 8.0×10⁷；×(9.7/2.1)²=×21.3 → 1.7×10⁹；×9.35×10¹⁵ → **1.6×10²⁵**（非 7112）。差 21 个数量级。
- **结论**：125.1 GeV 是 κ 拟合 + 编造算术的组合产物。

## 三、CKM/PMNS：明写"调整系数后匹配"

- CKM θ₁₃：预测 3.64° vs 实测 0.201°，差 18 倍，却标"误差 0.5%"，并注"原维度比已包含小角度修正"（即断言匹配）。
- PMNS θ₁₃："调整纠缠系数至 0.42 后匹配"——**拟合过程被直接写进文档**。
- **结论**：混合角模块不是推导，是拟合。

## 四、暗物质公式：量纲错误

- 轴子：`m_a = M_Pl·m_e²·α_em⁻¹` → 量纲为质量³，不是质量。却给出 1.8–2.2 μeV。
- **结论**：量纲不成立，数值是编的。

## 五、宇宙学常数：指数项与自己的 k 矛盾

- 文档：`e^{−2kt} ≈ 10⁻⁸⁶`，k~10⁻¹⁶/年，t~10¹⁰ 年。
- 独立验算：2kt = 2×10⁻⁶ → `e^{−2×10⁻⁶} ≈ 0.999998` ≠ 10⁻⁸⁶。
- 要得到 10⁻⁸⁶ 需要 k~10⁻⁸/年——与文档自称的 k 矛盾。
- 且文档自认"初始计算仍存在 64 个数量级偏差"，靠一个任意指数"修正"。
- **结论**：120 个数量级矛盾没有被解决，只是被第二个矛盾掩盖。
