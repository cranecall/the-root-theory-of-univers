## 一、降频演化标准方程（你要找的那个）

### 1.1 离散形式（体系原律，保留）

```
E_{n+1} = k·E_n,   k = 1/φ = 0.618034
E_n = E_P·φ^{-n}                    （等价 f_n = f_P·φ^{-n}，因 E ∝ f）
```

### 1.2 连续形式（新，纯改写）

设时间 = 迭代计数：`t = n·t_P`（文档 Part B 已有），则：

```
E(t) = E_P·e^{-γt}
γ = ln(φ)/t_P ≈ 0.4812 / 5.391×10^{-44} s ≈ 8.93×10^{42} s^{-1}
```

红移式写法：`1+z = E_P/E(t) = φ^n = e^{γt}`

这就是"降频演化的标准方程"：**纯指数衰减，零自由参数**（γ 完全由 φ 和 t_P 固定）。它和体系所有已通过验证的公理相容。

### 1.3 里程碑修正表（原来的 38/64 位置错了）

用体系自己的 `E_n = E_P·φ^{-n}` 反推各阈值的真实步数（E_P = 1.22×10¹⁹ GeV）：

| 里程碑 | 原表步数 | 原表能量 | 按标度律真实步数 | 真实能量 |
|---|---|---|---|---|
| 普朗克 | 0 | 1.22×10¹⁹ GeV | 0 | 1.22×10¹⁹ GeV |
| 第一次破缺 | 7 | ~10¹⁶ GeV | **15** | 8.9×10¹⁵ ≈ 10¹⁶ GeV |
| 电弱破缺 | 14–20 | ~100 GeV | **82** | ~89 ≈ 100 GeV |
| 强子化 | 38 | ~1 GeV | **92** | ~0.72 ≈ 1 GeV |
| 原子形成 | 64 | 13.6 eV | **129** | ~12.3 ≈ 13.6 eV |
| 化学/分子 | >100 | ~eV | **134** | ~0.76 eV |

**ΔN=38 的正确身份（关键修正）**：38 不是"普朗克→强子"的步数，而是**强子→原子**的间隔：

```
频率口径: ΔN = log_φ(f_强子/f_原子) = log_φ(10^8) = 18.421/0.4812 = 38.28 ≈ 38
能量口径: ΔN = log_φ(E_强子/E_原子) = log_φ(7.35×10^7) = 18.11/0.4812 = 37.6 ≈ 38
```

两个口径都给出 ≈38，误差 <1%。**"38"作为整数可以保留，但它的角色必须改**：它是强子到原子之间的降频间隔，不是普朗克到强子的累计步数。

## 二、八处修订

### 2.1 张力公理（原 2.1 矛盾：O-2 说复合=id，演化说复合≠id）

**修订**：把 O-2 拆成"理想态 + 实际态"两层：

```
O-2（理想闭合，保留）: f_A∘f_B∘f_C = id_A（循环成立）
O-2'（张力公理，新增）: 对任意实际例示，存在残差
    T = ‖f_A∘f_B∘f_C − id_A‖ > 0
    T_{n+1} = k·T_n（随迭代以 k 衰减，永不归零）
```

这样"如果复合严格等于 id 就什么都没有"成为理想极限陈述，动力源 T 成为实际残差，两者不再冲突。

### 2.2 ΔN=38 的支撑恒等式（原 2.2：`2λ^{-3}+3λ^{-2}≈1` 算错）

**删除该恒等式**（实算：`2×0.236068 + 3×0.381966 = 1.618034 = λ ≠ 1`），替换为：

```
ΔN(强子→原子) = ln(10^8)/ln(φ) ≈ 38.3 ≈ 38
```

不再声称"唯一确定"，改称"强子与原子阈值之间频差的整数近似"。

### 2.3 时间线步数（原 2.3）

按 1.3 的修正表整体替换：7→15（或保留"7 步= k⁷ 机制"但能量改为 4.2×10¹⁷ GeV）、14–20→82、38→92（作为累计步数）、64→129；38 转职为间隔数。**注意**：k⁷ 机制（第二次破缺）与"100 GeV"不能同时成立——k⁷=1/29 从普朗克给出 4.2×10¹⁷ GeV；若坚持电弱 100 GeV，则破缺发生在 k⁸²。二选一，推荐后者（与标准能量表一致）。

### 2.4 质量公式量纲（原 2.4：`ℏc/l_P` 是能量不是质量）

**修正量纲**：质量维前缀应为 `ℏ/(c·l_P)`（实算 = √(ℏc/G) = 普朗克质量 m_P），并把物理耦合显式化：

```
m_p = m_P·3λ²·C_p，   m_P = ℏ/(c·l_P) = √(ℏc/G)
m_e = m_P·2λ^{-1}η^{-1}·C_e
纯φ部分之比: m_p/m_e = 3λ²/(2λ^{-1}η^{-1}) = 8.68
要达到 1836，需 C_p/C_e = 211.5
```

C_p、C_e 标注为 [需物理公理] 的占位耦合常数（对应你第六部分要求的"耦合公理"），不能宣称纯数学导出。**必须删除**"由这两式给出 1836"的隐含说法——纯φ部分只给出 8.68。

### 2.5 λ³⁸ 数值与 m_p/m_e 表述（原 2.5）

```
λ^38 = e^{38×0.481212} = 8.78×10^7   （原文 1.25×10^8 偏大约 40%）
m_p/m_e = 1836 ⟺ 拓扑耦合常数 C ≈ 1836/8.78×10^7 = 2.09×10^{-5}
```

表述改为："λ³⁸ 超调 1836 约 4.8 万倍，需要拓扑耦合常数 C≈2.09×10⁻⁵ 才能回到 1836；C 的来源属于 [需物理公理]，不是纯数学结果。"（与中文形式化版自认一致）
