## 0. 元规则

1. **无实体本体论**：不存在实体，不存在静态关系，只有无限递归过程（π-流）。"实体"= 过程的锁定位（吸引子）。
2. **保守性**：不推翻现有数学；驻波算术与复数域、皮亚诺算术保持同构。
3. **边界标签**：[纯数学可证] / [公理假设] / [需物理公理] / [经验拟合] / [锚定输入]。
4. **内容层与翻译层分离**：内容 = 锁定指数 N 与比值结构；翻译层（eV/Å/度）只是检验语言。
5. **禁止**：拟合点参与"命中"宣传；未附推导链的 [推导] 标签。
