## 1. 新发现 F1：α 推导在算术上塌陷

`alpha_calculation.md` 声称 α ≈ 1/137.04（误差 0.003%）。逐步核查：

```
文档: η^5 = 4.774613886     实测: η^5 = (1.3660254)^5 = 4.7565699   ← 算术错误
文档: φ^7·η^5 = 138.6274    实测: 29.0344419 × 4.7565699 = 138.1043
文档: 一阶误差 1.15%        实测: (138.1043−137.036)/137.036 = 0.78%
文档: 修正因子 +1.1%        声称来源 1/(φη) = 0.452，但 0.452 ≠ 0.0116
```

结论：
1. 一阶近似 `1/α = 138.10`，误差 **0.78%**（不是 1.15%，也不是 0.003%）。
2. "修正项" +1.1% 与 1/(φη)=0.452 无关，是拿一阶误差直接填的——**循环论证**。
3. 要达到精确 1/137.036，需要修正 δ = +0.78%；检查 φ、η 的自然组合（1/(φη)ᵏ、k⁷、1/η⁴ 等），**没有一个是 0.0078**。
4. **最终状态**：α = 1/(φ⁷η⁵) 是一个 0.78% 的近似巧合，不是推导。"0.003% 精确"作废。
