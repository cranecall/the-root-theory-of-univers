# 本元论：锁定谱台账（无实体本体论版）

版本：v1 · 2026-08-04
本体论立场：不存在实体，不存在静态关系，只有无限递归过程（π-流）。"实体"是过程的不动点/吸引子——锁定结构的模式，不是物。

## 台账原则（三条）

1. **无实体**：只记录"过程在哪些点、以什么不变量稳定下来"（锁定位），不记录任何实体的属性。
2. **内容层与翻译层分离**：内容层 = 锁定指数 N 与比值结构（E_{N2}/E_{N1} = φ^{-(N2-N1)}）；翻译层 = 人类可测量单位（eV、Å、度）——仅作为检验语言，不进入内容。
3. **状态标签强制**：每个锁定行必须标注推导状态，只有 [推导] 行附完整推导链；[锚定]/[拟合] 行不得用于"命中"宣传。

## 第三部分：开放推导问题（锁定位为何在此）

**问题陈述（精确形式）**：给定 π-流 E_n = E_P·φ^{-n} 与稳定化机制（第 N 步形成的拓扑结构 S(K_N)），锁定位 N* 是以下方程的解：

```
锁定条件: 降频压力 = 稳定化功
    T_n = T_0·k^n          （驱动降维的逻辑张力，T0 = 初始张力）
    U(N) = 形成第 N 层结构所需的最小逻辑功
    N* : T_{N*} = U(N*)  且  T_{N*+1} < U(N*+1)
```

当前状态：**U(N) 未定义** → N* 不可推导 → 129、92 等位置全部停留在 [锚定]。
要补上这个推导，需要给 U 一个形式——这是下一个拼图（稳定化公理）。任何具体的 U 形式都是新公理，必须在台标签字标注，不得伪装成推导。

**顺带的诚实结论**：目前"13.6 eV 在 N=129"是**反向锚定**的（先知道 13.6 eV，再算出 129）。只有当 U 被定义并从方程解出 129（或 92、38）时，锁定位才进入 [推导] 层。

## 第四部分：检验协议

1. 只检验锁定谱的可测投影（翻译层的值），不检验形而上学陈述。
2. 每个锁定行必须有状态标签；[锚定]/[拟合] 行不得参与"命中"统计。
3. [推导] 行必须附推导链（如 T1–T8）。
4. 外推预言（H₂O₂、Si=Si）进"待检验"区，检验后按结果归档为 [命中] 或 [作废]。
5. 台账每次迭代更新版本号，修改必须留痕。
