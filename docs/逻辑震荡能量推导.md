# 逻辑震荡能量推导（从零开始）

日期：2026-08-04
方法：只使用体系已有公理（降频律 k=1/φ）与一个起点定义（逻辑震荡能量）。所有算术可复核，检验数据来自 PDG 已知质量。不预知答案。

---

## 0. 起点定义

**逻辑震荡**：周期 = 普朗克时间 t_P = 5.391×10⁻⁴⁴ s（体系已有）。
**逻辑震荡能量**（本推导唯一定义）：

```
E_osc = h·f_P = h/t_P = 7.671×10^19 GeV = 2π·m_P·c²
```

（注意：这是 h 版震荡能量；若用 ℏ 则等于 E_P。见第 4 节比较。）

**迭代深度 N**：结构在第 N 步锁定，其质量 = 该步的震荡能量：

```
m_N = E_osc·φ^{-N}     （GeV）
```

## 1. 推导链（三步）

1. 逻辑震荡能量：`E_osc = h/t_P = 7.671×10^19 GeV`（定义）
2. 降频律（体系公理）：每步衰减 k=1/φ → `E_n = E_osc·φ^{-n}`
3. 质量-锁定假设：`m_N = E_osc·φ^{-N}`（结构在迭代深度 N 锁定，质量等于该深度震荡能量）

## 2. 检验：已知粒子落在哪个 N

```
N = ln(E_osc / m) / ln φ
```

| 粒子 | m (GeV) | N | 最近整数 | 偏差 |
|---|---|---|---|---|
| e | 5.110×10⁻⁴ | 110.90 | **111** | +0.10（0.09%） |
| μ | 0.10566 | 99.82 | **100** | +0.18（0.18%） |
| τ | 1.7769 | 93.95 | **94** | +0.05（0.05%） |
| π± | 0.13957 | 99.24 | — | 不接近整数 |
| p | 0.93827 | 95.28 | — | 不接近整数 |
| n | 0.93957 | 95.28 | — | 不接近整数 |

**轻子（e/μ/τ）全部落在近整数迭代深度：111 / 100 / 94，偏差全部 < 0.2%。**
**强子（π/p/n）不落在整数深度。**

## 3. 发现

1. **轻子谱 = 迭代深度**的结构直觉得到支持：e/μ/τ 确实坐在 φ 降频阶梯的整数深度上（111/100/94）。
2. 这与体系"轻子=迭代深度、强子=纽结拓扑"的说法方向一致——强子不落在整数深度，符合"强子是纽结不是纯降频"。
3. 用户参考文档里的具体公式 `m = m_e·(n + ln(m/M_Pl))` 是错的（无解），但**"轻子=迭代深度"这个核心直觉是对的**——正确的形式是 `m_N = (2π·m_P)·φ^{-N}`。

## 4. 诚实判定（关键）

**这是近模式，不是推导。** 原因：

1. **质量偏差仍有 4–9%**：N 偏差 0.05–0.18 在质量空间放大为 φ^{0.18}−1 ≈ 9%。即 e/μ/τ 的预测质量分别偏 ~4% / ~9% / ~1%。不是精确命中。
2. **整数间隔无规则**：μ/e = φ^{11.08}，τ/μ = φ^{5.87}——间隔 11 和 6 的来历没有任何推导。
3. **巧合概率 ~5%**：三个质量都落在某整数 N 的 0.2% 内，随机概率约 (0.36)³ ≈ 5%；且 h/t_P 与 ℏ/t_P 的选择本身是一种选择效应（用 ℏ 版只有 μ 干净），真实显著性更低。
4. **与之前所有"命中"的区别**：这次不是反向凑数——是先定义起点、再检验，方向正确；但正确方向 ≠ 成立。

**对比两种能量归一化：**

| 归一化 | e | μ | τ |
|---|---|---|---|
| E_osc = h/t_P | 110.90→111 | 99.82→100 | 93.95→94 |
| E_P = ℏ/t_P 系 | 107.08（偏） | 96.00（精确） | 90.13（偏） |

h 版三者全近整数，ℏ 版只有 μ 精确——h 版结构更一致，但"选 h 不选 ℏ"没有体系内依据（体系自己混用了 h 和 ℏ）。

## 5. 结论与下一步

**结果**：从逻辑震荡能量出发，三步推出"轻子质量 = (2π·m_P)·φ^{-N}"，且 e/μ/τ 的 N 落在 111/100/94（<0.2%）。这是全部工作中第一个**方向正确、可复核、结构上自洽**的从零推导——但它还不是命中。
