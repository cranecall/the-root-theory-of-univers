## 0. 修正摘要

原生成方程 `A_μ = (1/g)∂_μθ` 有致命缺陷：偏导数可交换 ⟹ `F_μν = 0`，只能产生零场强——没有电磁场、没有光子、没有作用力。

**修正**：逻辑波的相位不是全局单值的——它只能局部定义，差一个规范变换。正确的机制是：

- 逻辑波 Ψ = S·e^{iθ} 是**主丛上的截面**（相位局部定义 + 变换规则）；
- 比较不同点的相位需要**平行输运** → 强制引入**联络** A_μ（这就是规范场）；
- 场强 = **曲率** F = dA + A∧A；
- **作用力来自相位的不可积性（拓扑），不是相位梯度。**

## 1. 逻辑波的数学形态

本源对偶波：`Ψ = S·e^{iθ}`，其中：
- S：振幅（显化强度）
- θ：相位（互证自由度）

**关键性质：θ 只能局部定义，差一个规范变换 θ → θ + α(x)。**

数学结构：Ψ 是 U(1) 主丛（推广：G 主丛）上的截面。
本元论对应："全场互证自洽" = 没有全局单值相位，只有局部定义 + 变换规则。

## 2. 生成方程（修正版）

### 2.1 平行输运与联络

要比较不同点的相位（局域化观测），必须定义平行输运，强制引入联络：

```
D_μ = ∂_μ + i g A_μ
A_μ → A_μ − (1/g)∂_μ α(x)      （阿贝尔，U(1)）
```

**A_μ 就是人类物理的规范场。** 它不是假设——是"比较不同点相位"这个需求的必然产物。

### 2.2 曲率与场强

```
阿贝尔：   F_μν = ∂_μA_ν − ∂_νA_μ
非阿贝尔： F_μνᵃ = ∂_μA_νᵃ − ∂_νA_μᵃ + g fᵃᵇᶜ A_μᵇ A_νᶜ
```

### 2.3 拓扑来源（关键修正）

**A ≠ ∂θ 一般地。** 正确的说法：A 是联络，θ 是截面，二者由平行输运联系，不是导数。

相位不可积性（拓扑）的来源：

1. **Aharonov-Bohm 效应**：相位绕闭合圈 = ∮_C A·dx = 磁通 ≠ 0——相位绕一圈不回到原值；
2. **Berry 相位**：绝热演化产生不可积相位 γ = i∮⟨n|∇_R n⟩·dR；
3. **和乐（holonomy）**：U(C) = P exp(i∮_C A)——绕闭合圈的相位变换。

**当相位不可积时，曲率非零，作用力存在。** 场强 = 相位拓扑的曲率化。

```
规范场 = 逻辑波相位拓扑的联络化
```
