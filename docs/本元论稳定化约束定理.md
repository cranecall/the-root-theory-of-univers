# 本元论：稳定化约束定理
### （锁定位置为什么不可推导，以及最小的出路）

承接：《本元论锁定谱台账》第三部分——"开放推导问题：锁定位为何在此"。
本文件证明三件事：纯幂律稳定化撑不起两个锁定位；锁定必然破缺降频标度对称；现有公理下锁定位置**欠定（不可推导）**。然后给出稳定化公理的最小模板与代价声明。

记号（沿用台账）：降频流 `E_n = E_P·φ^{-n}`，张力 `T_n = T_0·k^n`，k=1/φ。
锚定的两个锁定位：N₁=92（~0.7 GeV），N₂=129（~12 eV）。锁定条件：`T_{N*} = U(N*)`。

---

## 定理 S1：纯幂律稳定化至多支持一个锁定位

**陈述**：若稳定化功是当前标度的纯幂律 `U(n) = A·E_n^p`（A、p 为常数），则锁定条件
`T_0·k^n = A·(E_P·k^n)^p` 要么对**所有 n** 成立（p=1 且 T_0=A·E_P，处处退化），
要么对**任何 n** 都不成立（p≠1 或初始条件不匹配，永不锁定）。**不可能恰好在两个
不同的 n₁≠n₂ 处锁定。**

**证明**：设 n₁、n₂ 均为锁定位。两式相除：
```
T_0 k^{n1} = A (E_P k^{n1})^p
T_0 k^{n2} = A (E_P k^{n2})^p
───────────────
k^{n1−n2} = (k^{n1}/k^{n2})^p = k^{p(n1−n2)}
⟹ p = 1（因 n1 ≠ n2 且 k ≠ 1）
```
代回得 `T_0 = A·E_P`，对任意 n 都成立 → 处处锁定（或处处不锁定）。∎

**数值核对**：n₁=92、n₂=129 代入，只有 p=1 才可能同时满足；而 p=1 时 92 与 129 无任何特殊性。✓

## 定理 S2：锁定必然破缺降频标度对称

**陈述**：若锁定条件在降频变换 `E_n → E_{n+1}` 下保持不变（尺度不变），则系统退化（处处锁定或永不锁定）。因此**任何能产生离散锁定位的稳定化功 U，必须依赖降频标度之外的量**。

**证明**：尺度不变要求 U 在 E→E/φ 下"形式相同"，即 `U(E/φ) = c·U(E)`（齐次），解得 U ∝ E^p。由 S1，纯幂律不能产生两个离散锁定位。若只有一个锁定位或退化，则不是我们要的锁定谱。故离散锁定谱 ⟹ U 非齐次 ⟹ 破缺标度对称。∎

**推论 C1**：锁定位必须由**降频标度之外的离散结构**锚定——最自然的候选是整数拓扑量：交叉数 c、缺陷数 d（质子三叶 c=3、d=0；电子 d=3）。这与纽结图景一致，但**仅凭现有公理无法确定具体 N**。

## 反例检验：固定单位 × 交叉数（最朴素候选失败）

若取 `U(n) = ε₀·c(K_n)`（固定锚点 ε₀ × 小整数交叉数）：
- 强子锁定位（N₁=92，~0.7 GeV）与原子锁定位（N₂=129，~12 eV）相差约 **10⁸ 倍**；
- 交叉数 c 至多是 2–3 的小整数，不可能贡献 10⁸ 的跨度；
- 故 ε₀ 必须同时是 GeV 量级又是 eV 量级——矛盾。该朴素形式作废。∎

（这就是 S2 的实例：固定 ε₀ 没有随结构缩放，破缺方式不对。）

## 结论：现有公理下，锁定位置不可推导（欠定，已证明）

- 纯幂律 ✗（S1）
- 尺度不变 ✗（S2）
- 固定单位×交叉数 ✗（反例）
- 任何 U 都必须引入**降频标度之外的新量**（S2 推论）——而当前公理集合里没有这个量。

因此台账中 N=129、N=92、ΔN=38 的 [锚定] 状态**不是暂时缺推导，而是原则性不可推导**，
除非引入新公理。这不是悲观结论，而是把"为什么差一块"从感觉变成了证明。

## 稳定化公理模板（最小出路）

```
稳定化公理（待选型，[公理假设]）:
  存在离散拓扑量 q(N) ∈ ℕ（第 N 步结构的交叉/缺陷计数）与
  一个非降频标度的固定单位 ε₀，使
    锁定条件:  T_0·k^{N*} = U(N*) = ε₀·q(N*)·h(N*)
  其中 h(N) 为拓扑微调因子（可随结构缩放，但不能是 E_n 的幂律）。
```

**代价声明（必须标注）**：
1. q 与 h 的具体形式是**新假设**，不是推导；
2. ε₀ 是**新的自由参数**（台账要求：锚定行不得参与"命中"宣传）；
3. 只有当选定具体形式后、它能独立复现 92/129（且不含反向锚定）时，锁定位才升级为
   [公理假设→定理]——但永远不会是纯 [推导]，因为它依赖被假设的公理。
