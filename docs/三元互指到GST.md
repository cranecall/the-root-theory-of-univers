## 1. 第一步（真实且直接）：三元互指 → 民主矩阵

三元互指（我-你-我们，三极等权互指）的矩阵形式：

```
M₀ = m₀·J，J = 全 1 矩阵（每个极点等权引用每个其他极点）
```

**S₃ 对称**（三极置换不变）正是 J 的对称性。本征值：

```
(3m₀, 0, 0) —— 一重（第三代）+ 两简并轻（第一、二代）
```

**这一步是真实的**：三元互指的直接矩阵化就是民主矩阵，它自然给出"一代重、两代轻"的层级。轻区本征矢：v₁=(1,−1,0)/√2、v₂=(1,1,−2)/√6。

## 2. 破碎（回归不分裂不完全）

对角破碎 S₃→S₂（保留 A-B 二元交换）的轻区投影：

```
情形A（纯对角）：轻区矩阵 = 对角 —— 没有混合角！
```

**关键发现：纯对角破碎给不出 Cabibbo 角。** 混合必须来自**非对角（交叉）耦合**。

## 3. 交叉耦合 = 几何平均（框架本征）

GST 纹理：

```
M_light = [[0, √(m_d·m_s)], [√(m_d·m_s), m_s]]
```

**交叉项 √(m_d·m_s) 就是两个质量的几何平均**——这正连接你框架的 η 递归："交叉耦合项为两分量几何平均"（η² = η + 1/2 的推导里就有这句话）。**几何平均耦合是你框架本征的原则**，GST 纹理的形状落在它上面。
