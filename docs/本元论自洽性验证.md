## 二、硬性内部矛盾（附算术）

### 2.1 公理 O-2 与宇宙动力源直接冲突（最深的一处）

- 公理 O-2（两份文档都有）：三元结的循环复合**等于恒等**——`f_A∘f_B∘f_C = id_A`（循环成立）。
- 宇宙演化章节：宇宙唯一动力源是张力 `T = ‖f_A∘f_B∘f_C − id‖ ≠ 0`，"如果复合严格等于 id，闭环完全自洽，张力为零，什么都不会发生"。

同一对象，一处说复合=恒等，一处说复合≠恒等（且全宇宙都靠这个非零驱动）。若按公理，则张力恒为零，宇宙演化章节整体失效；若按演化，则公理 O-2 不成立。二者不能同时为真。修复需要明确声明"公理描述理想闭合、动力学描述实际残差"，但文本现在把两者都写成事实。

### 2.2 ΔN=38 的支撑恒等式算错

- 声称 `2λ⁻³ + 3λ⁻² ≈ 1`，由它"唯一确定 ΔN=38"。
- 实算：`2λ⁻³ = 2×0.236068 = 0.472136`；`3λ⁻² = 3×0.381966 = 1.145898`；**和 = 1.618034 = λ，不是 1**。
- 且文档自己的能量比计算（4.3节）：`ln(E_P/E_H)/ln λ = 62.06/0.48121 = 128.97`，与 38 无任何推导关系。
- 结论：38 没有给出任何真实推导，"唯一确定"不成立。

### 2.3 时间线步数与其自身标度律矛盾

- 体系标度律：`f_N = f_P·k^N`（频率每步乘 k），能量同理 `E_N = E_P·k^N`。
- 时间线表：38 步 → 强子 ~1GeV；64 步 → 原子 ~13.6eV。
- 用体系自己的标度律反推步数：
  - 能量口径：`E_P/1GeV = 1.22×10¹⁹ → N = ln(1.22×10¹⁹)/ln(1/φ) ≈ 91.6`，不是 38；`E_P/13.6eV = 8.97×10²⁶ → N ≈ 129`，不是 64。
  - 频率口径：`10⁴³→10²³ Hz` 需 `N ≈ 95.7` 步；`10⁴³→10¹⁵ Hz` 需 `N ≈ 134` 步。
- 无论按能量还是按频率，38 和 64 都对不上。且 E=hν 下能量与频率指数相同，不存在"能量步数≠频率步数"的换算空间。

### 2.4 质子/电子质量公式：量纲与量级自相矛盾

- `m_p = (ℏc/l_P)·3λ²`，`m_e = (ℏc/l_P)·2λ⁻¹η⁻¹`。
- 量纲检查：`ℏc/l_P` 是普朗克**能量**（1.22×10²⁸ eV），不是质量。
- 量级检查：`m_p ≈ 1.22×10²⁸ × 7.854 = 9.6×10²⁸ eV ≈ 10²⁰ GeV`，与系统自己表格里"强子 ~1GeV"差 10¹⁹–10²⁰；`m_e ≈ 1.10×10²⁸ eV`，与"电子 ~0.5 MeV"差 ~10²²。
- 更关键的自相矛盾：由这两式得出的**比值** `m_p/m_e = 3λ²/(2λ⁻¹η⁻¹) = 7.854/0.9049 = 8.68`，而系统在别处主张 `m_p/m_e ≈ 1836`。自己的两个公式合起来不支持自己的比值主张。

### 2.5 m_p/m_e 的 λ³⁸ 表述错误

- 声称"λ³⁸ 本身已覆盖 1836 的绝大部分"。
- 实算：`λ³⁸ = e^(38×0.48121) = 8.78×10⁷`（文中写 1.25×10⁸ 也偏大约 40%）。8.78×10⁷ 比 1836 大 **4.8 万倍**，方向相反——不是"覆盖绝大部分"，而是超调 5 个数量级。
- 中文形式化版自己承认："φ³⁸≈1.25×10⁸ 量级不对，必须引入额外耦合常数"。英文版与中文版在此直接矛盾。

### 2.6 化学键验证表：n 列与公式、r 列都不一致

- 公式：`n = 2 + α(T)(Z−1)(η/λ) − LP − (m−1)P`，`r = (λ/η)^n·a₀`。
- 抽查（η/λ = 0.844260，λ/η = 1.184472，a₀ = 0.529177Å）：

| 键 | 公式算的 n | 表列 n | 表列 r 反推的 n | r 与公式是否吻合 |
|---|---|---|---|---|
| H-H | 2.000 | 2.000 | 2.00 | ✓（唯一一致行） |
| C-C | 6.221 | **7.417** | 6.23 | r 吻合，n 列错 |
| C=C | 5.486 | **6.682** | 5.51 | r 吻合，n 列错 |

- 结论：r 列大致由公式可复现（拟合痕迹），n 列则与公式、与 r 列都不一致。验证表内部不自洽。

### 2.7 投影公理与"氢原子不动点"直接冲突

- 定义3.2：对所有 `X ≠ ∅_K`，`π(X) ≺ X`（**严格**降维）；唯一不动点是 `∅_K`。
- 宇宙演化："氢原子……是第一个满足**投影不动点条件 π(X)=X** 的稳态结构"。
- §11 锁定条件：`⊣(K)=K ⟺ π(K)=K`。
- 若 π 对一切非基态严格降维（π(X)≠X），则氢原子不可能是 π 的不动点；若氢原子是 π 的不动点，则严格性公理被违反。二者只能留一个（除非把"锁定"重新定义为"不再应用 π"，但文本明确写了 π(X)=X）。

## 五、最小修复清单（按自洽标准）

1. **张力公理化**：明确 `f_A∘f_B∘f_C = id` 是理想极限，动力源张力是实际残差，并把 O-2 改为"≈id + 残差 T"或单独设"张力公理"。

3. **时间线口径**：统一标度律与步数——要么步数改 91.6/128.9（能量口径），要么给出能产出 38/64 的明确新标度律（注意 E=hν 使频率/能量口径指数相同，需另立机制）。

7. **π 与锁定**：把"基态锁定"重定义为"π 迭代的停机条件（系统选择停止）"，去掉 `π(X)=X` 的字面表述，或放宽严格性公理。
