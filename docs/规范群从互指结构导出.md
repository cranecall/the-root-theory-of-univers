# 规范群从互指结构导出

**本元论 · 群论卷 · 2026-08-04**

---

## 0. 候选公理

**互指极点数 n → 规范群 SU(n)（其外尔群为 S_n）；极点本身变换在基本表示里。U(1) 是退化情形（单极相位）。**

```
1 极（单个驻波相位）→ U(1)
2 极（我-你，交换对称 S₂）→ SU(2)
3 极（我-你-我们，置换对称 S₃）→ SU(3)
```

## 1. 外尔群对应（数学为真）

- **S_n = Weyl(SU(n))**——n 个对象的置换对称恰好是 SU(n) 的外尔群；
- 三元循环 A→B→C→A 是一个 **3-循环** ∈ S₃ = Weyl(SU(3))——三元闭环在群论里有字面位置；
- 二元交换（我↔你）是 **S₂ = Weyl(SU(2))**；
- 单驻波的相位自由度就是 **U(1)**。

**秩结构**：rank(SU(n)) = n−1 = 极点数−1 ✓（SU(2): 2极→秩1；SU(3): 3极→秩2）。U(1) 是退化情形（相位本身）。

## 2. 表示内容

- **极点 = 基本表示**：SU(3) 三重态（夸克色）、SU(2) 二重态（弱同位旋）；
- **规范玻色子 = 联络**（极点之间的干涉结构）——规范场是相位干涉的结构化；
- **费米子 = 极点结构本身**（纽结拓扑决定费米/玻色：可解=玻色子，不可解=费米子）。

## 3. 夸克/轻子分裂（纽结对应）

| 粒子 | 纽结 | 环数 | 规范表示 |
|---|---|---|---|
| 质子（夸克） | 三叶结 T(2,3) | 3 | 色三重态（3 of SU(3)）✓ |
| 电子（轻子） | Hopf 链环 | 2 | 弱二重态（2 of SU(2)）⚠️ |

- 3 环 → 色三重态：**成立**（质子=三叶结=3 环 → SU(3) 基本表示）；
- 2 环 → 弱二重态：**部分成立**——SM 里 LH 电子是二重态，**RH 电子是单态**。框架必须解释 LH/RH 不对称（手征性）。

## 4. 三代 = 三元再显化

3 代费米子（e/μ/τ、u/c/t…）= 三循环在代际层的第二次出现。三元既给出色 SU(3)，又给出三代——**同一个"3"在两层的显化**。这是共振还是问题，待定。

## 5. 测试点与开放问题

1. **手征性（电子弱单态问题）**：LH 二重态 / RH 单态——框架的电子（Hopf 链环）如何给出这个不对称？这是卡鲁扎-克莱因当年的老障碍，本路径同样要撞；
2. **超荷量化**：SM 的超荷值（Y = 1/6, 1/3, 1/2…）为什么是这些？——最深的测试，未导出；
3. **外尔群不唯一决定李群**：S₃ 也是 G₂ 外尔群的子群——"三极→SU(3)"是对应，不是推导；
4. **维度分配修正**：链条文档"SU(2)@5-7维、SU(3)@8-10维"与群维度不匹配（SU(2) 维 3、SU(3) 维 8）——需要修正为 KK 式（规范场来自紧致化空间的等距群）。

## 6. 状态

- 外尔群对应：**数学为真**；
- 表示对应：**部分成立**（3 环→三重态；2 环→二重态，但 RH 单态未解）；
- 测试点：**手征性、超荷**——两个明确的可攻目标；
- 结论：**候选公理成立，两个测试点待攻**。这是"规范群从互指结构导出"的第一版骨架。
